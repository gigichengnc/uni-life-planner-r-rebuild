# Problematic-Code-Uni

A retrospective reconstruction of a Year 1 project from **STAT 2610SEF Data Analytics with Applications**.

## Project theme

**From Words to Programs: R-Based Student Events Feedback Analysis**

The original 2025 Spring group project, *UNI LIFE PLANNER*, explored student reflection journals using R-based text mining, topic modelling, sentiment analysis, word clouds, and activity recommendations.

This repository is being reconstructed in two layers:

- **Historical layer** — preserve what was actually built in Year 1, including its limitations.
- **Reconstruction layer** — document the problems, make the code reproducible, and redesign the analysis more carefully.

> The original raw reflection journals and other potentially identifying/private data are not published here by default.
