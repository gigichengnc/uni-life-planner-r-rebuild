# Original Year 1 implementation

This directory preserves a reconstruction of the R code shown in **Appendix 1A** of the original STAT 2610SEF project report.

## What is preserved

`original_from_report.R` is a transcription of the code printed in the submitted report. Line wrapping introduced by the PDF layout has been repaired where necessary so that the intended R statements are readable.

It is **not** presented as corrected code. Known issues are documented separately in `../docs/known-problems.md`.

## What is intentionally not included yet

The original 10 reflection-journal text files and the unredacted report are not included in the public-ready structure because they contain personal information and/or material whose redistribution permissions should be reviewed first.
