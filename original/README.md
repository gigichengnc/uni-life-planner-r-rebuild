# Original Year 1 implementation

This directory preserves the **Year 1 Baseline v1** for the STAT 2610SEF project.

## Baseline status

`reconstructed_year1_code.R` is reconstructed from the R code printed in **Appendix 1A** of the original submitted course report. PDF line wrapping and formatting have been repaired where necessary so that the intended R statements are readable, but the original analytical logic is intentionally preserved.

This file is now treated as a **frozen historical baseline**. It should not be refactored or gradually corrected. All improved implementation work belongs in `../R/`, allowing a genuine before/after comparison.

## Why preserve it

The purpose of this repository is not only to present cleaner code. It is to show the progression from a Year 1 attempt to a more reproducible, statistically defensible, and maintainable implementation. Known problems are documented in `../docs/known-problems.md`.

## What is intentionally not included

The original reflection-journal text files and the unredacted report are not published in this public-ready structure because they contain personal information and/or material whose redistribution permissions should be reviewed first.
